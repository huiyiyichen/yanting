# 插件「辅助 / 档案 / 轨迹」重做计划（2026-10-15）

对照：05_前端视觉方案/yanting-concept-plugin.html。现状：只做了样式，数据层缺“关注点/已拒绝做法/待兑现承诺/诉求/回复依据”。

## A. 辅助页（按概念稿，前后端一起补）
1. 客户摘要卡：近 N 天第几次进线、当前情绪与升级时间（已有 emotionHistory/contactHistory，前端组装）。
2. 关注点：
   - 关注话题 chips（从会话理解 understanding 的诉求/主题得出）。
   - 已拒绝做法：客户明确拒绝的处理方式（如“先拍照再核实”），新增后端抽取 `declined_approaches`，回复建议生成须避开。
3. 待兑现承诺卡：历史会话/工单中的客服承诺（金额、承诺内容、到期日、状态 待兑现/已逾期/已兑现），新增 `pending_commitments`，到期前高亮。只读展示，不执行任何打款。
4. 诉求 chips：仅退款 / 空包裹 / 拒绝举证 等，来自 understanding。
5. 回复建议卡：推荐/简洁/安抚 三风格切换；引用上下文片段金色高亮；要素标签（情绪回应/业务处理/个性化）；依据来源 chips（工单/订单/会话，可点开）；采用/编辑/改写。
6. 风险关注：“N 项待处理”计数，每项含触发原话引用 + 主操作（接管处理/详情）。
7. 下一步：可勾选清单，勾选写入服务轨迹。
8. 底部折叠：知识依据 / 订单与物流 / 售后工单（带计数）。

## B. 档案页（自由设计）
- 顶部身份条：昵称、会员/进线频次、总体情绪倾向迷你条。
- 偏好与禁忌：沟通偏好、已拒绝做法（与 A2 同源）。
- 历史诉求时间线（按会话聚合），承诺兑现记录，敏感度 0–3 指示。

## C. 轨迹页（自由设计）

- 顶部情绪曲线与节点对齐。
