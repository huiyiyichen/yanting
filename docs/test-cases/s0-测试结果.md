## 6. 开发过程中发现并修复的真实缺陷

这些是实际运行时暴露的问题，记录以便复盘：

1. **窄屏横向溢出 268px**：390×844 下客服侧固定 248+330px 面板超出视口。
   修复：按前端规范第 4 节实现抽屉与可收起列表；新增溢出回归用例。
2. **收起逻辑恒为真**：`showList = !isNarrow || listOpen` 使窄屏下收起操作无效。
   修复：改为可空的用户覆盖值 `listOpenOverride ?? !isNarrow`。
3. **窄屏聊天区被压至约 140px**：会话列表默认展开导致中文逐字换行。
   修复：窄屏默认收起会话列表。
4. **运行状态横幅在窄屏被裁切**：修复为窄屏用汇总标签 + 图标按钮。
5. **稀疏通道算法错误**：先做句级 mean-pooling 再投影，每条文本只得到 1 个词项权重。
   修复：改为逐 token 计算后按 token id 做 max 归约（15—25 个词项）。
6. **ONNX 导出无 `sparse_embedding`**：实现 `checkpoint_loader` 免 torch 读取
   `sparse_linear.pt`。
7. **`model_revision` 误报为 `onnx`**：修复为返回 snapshot commit hash。
8. **`MockEmbeddingProvider` 接受空输入**：与真实后端行为不一致，已对齐。
9. **Qdrant 未显式 `close()` 导致非 0 退出**：已在运行时代码中显式释放。
10. **Vite/Vitest 配置混写导致 `tsc -b` 失败**：拆分为 `vite.config.ts` 与
    `vitest.config.ts`。
11. **`tsc -b` 缺少 `composite`**：为两个子项目补上。
12. **枚举常量命名错误**（`CASESTATUS_VALUES`）：修复生成器的大小写转换。
