### 2.1 本轮已修复的「未通过」项（留档说明）

上一版本记录了一项未通过：**隔离环境下知识检索返回 `not_found`**。根因已定位并修复：

Qdrant 目录，隔离库因此没有 active 快照，`get_active_snapshot()` 返回 `None`，

（建表时需同时 `create_all` 两个独立的 `DeclarativeBase`——案件状态与知识库各有一个），

`hit_status=sufficient`、证据 5 条；AC-12 的申请字段随即有了样本（6/6）。

## 3. 已知限制（功能可用但受限）

1. **并发写**：同一会话 3 路以上同时发**不同**消息仍可能 500（SQLite 长事务持锁）。正常 UI 不可达（发送中按钮禁用）。见台账 6.1。
2. **会话列表性能**：一次性渲染全部会话，数百条时首屏约 3 秒；无虚拟滚动。见台账 6.2。
3. **混合检索无净增益**：三种模式在评测集上命中数相同（混合相对单路无净增益），**不得声称混合更优**。见台账 5.1。
4. **CAL-03 排序不足**：1 例真实排序缺陷保留为已知不足。
