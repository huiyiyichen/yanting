# 演示库

路演与日常开发使用不同的 SQLite 库，评测和校准脚本只写隔离库。

| 用途 | 库 | 知识索引 |
| --- | --- | --- |
| 日常开发（`-Profile dev`，默认） | `data/runtime/anker_agent.sqlite3` | `data/runtime/qdrant` |
| 路演（`-Profile demo`） | `data/runtime/demo.sqlite3` | `data/runtime/demo-qdrant` |
| 演示快照 | `data/runtime/demo-snapshot.sqlite3` | `data/runtime/demo-snapshot-qdrant` |
| 评测 | `data/runtime/eval-*.sqlite3` 或临时目录 | 评测脚本自建 |

`run_loreal_grounding_eval.py` 与隔离接待评测在目标库是上表前三个文件之一时直接拒绝运行（`app/runtime_guard.py`）。

## 构建与重置

```powershell
# 1. 构建快照：导入官方 Excel → 发布知识 → 写入剧情会话 → 风险扫描 → 测试命名检查
.\services\api\.venv\Scripts\python.exe -X utf8 scripts\build_demo_database.py
#    没有编码模型时加 --skip-knowledge（知识检索不可用）

# 2. 每次演练前恢复（后端须已停止）
.\scripts\reset_demo.ps1

# 3. 用演示库启动
.\start-demo.cmd -Profile demo
#    已有后端在跑开发库时加 -Restart
```

## 剧情

剧情会话定义在 `data/demo/storylines.json`，可直接编辑后重建快照。`customerViewId` 是客户页演示身份（启动时注入 `VITE_DEMO_CUSTOMER_ID`，也可用 `/customer?customer=苏**` 临时切换）。

| 剧情 | 会话 | 演示点 |
| --- | --- | --- |
| A 承诺未兑现 + 空包裹投诉 | 官方 S00005 → S00059 | 上次承诺与到期日、触发词、回复引用历史 |
| B 肤质个性化 | 本地 `conv-demo-b-skin`（苏**） | 自述肤质与更正、拒绝叠加面霜 |
| C 情绪升级与接管 | 本地 `conv-demo-c-logistics`（许**） | 已追问两轮，现场再发一条激烈消息触发升级与接管 |
| D 不良反应 | 官方 S00010、S00015、S00058 + 本地 `conv-demo-d-reaction`（温**） | 现场发“脸肿了，已经去医院”触发转人工；商品风险线索 |
| E 图片咨询 | `scripts/seed_loreal_real_product_demo.py` | 视觉识别商品 |

剧情会话由脚本直接写库，不调用模型，也不产生自动接待任务；现场发送的新消息才会走真实模型。
