# A1 Pro 无线吸尘器 产品资料

> 虚构夹具：本文件不是安克官方资料，仅用于本 Demo 的检索与证据链路联调。

## 产品定位

A1 Pro 无线吸尘器为手持杆式吸尘器，支持标准、强力、静音三档吸力，
配电动地刷、除螨刷与缝隙吸头。

## 主要规格

| 项目 | 参数 |
|---|---|
| 尘杯容量 | 0.6 L |
| 电池容量 | 2500 mAh（可拆卸） |
| 额定续航 | 标准档约 45 分钟，强力档约 12 分钟 |
| 充电时间 | 约 3.5 小时 |
| 滤网类型 | 五层旋风 + HEPA 滤芯 |

## 日常维护

1. 每次使用后清空尘杯，尘杯内积尘超过 MAX 线会明显影响吸力。
2. 每月清洗 HEPA 滤芯，必须完全晾干 24 小时后再装回。
3. 每 2 周清理地刷滚刷缠绕物与两端轴承。
4. 检查吸头接口与延长杆卡扣是否到位，接口漏气会直接削弱吸力。

## 常见现象与对应部位

| 现象 | 常见部位 |
|---|---|
| 吸力明显减弱 | 尘杯、HEPA 滤芯、地刷、吸头接口 |
| 吸力时强时弱 | 电池电量、档位切换、管道堵塞 |
| 无法开机 | 电池、电源键、充电触点 |
| 充电指示灯不亮 | 充电器、充电口、电池 |
| 边刷不转 | 地刷电机、传动皮带 |
