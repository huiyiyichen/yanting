# A1 Pro 扫地机器人 产品资料

> 虚构夹具：本文件不是安克官方资料，仅用于本 Demo 的检索与证据链路联调。

## 产品定位

A1 Pro 扫地机器人面向家庭地面清洁，支持扫拖一体、自动回充与地图记忆。
随机附带基站、边刷、滤网与拖布组件。

## 主要规格

| 项目 | 参数 |
|---|---|
| 集尘盒容量 | 0.35 L |
| 水箱容量 | 0.25 L |
| 电池容量 | 5200 mAh |
| 额定续航 | 约 150 分钟（标准模式） |
| 充电时间 | 约 4 小时 |
| 尘盒滤网 | 可水洗初效滤网 |

## 日常维护

1. 每次使用后清空集尘盒与水箱。
2. 每 2 周清洗尘盒滤网，自然晾干 24 小时后再装回；未完全干燥就使用会导致吸力下降并可能损伤风机。
3. 每周清理边刷与主刷缠绕的毛发。
4. 每月擦拭充电触点与传感器。

## 常见现象与对应部位

| 现象 | 常见部位 |
|---|---|
| 吸力下降 | 尘盒滤网、主刷、风道 |
| 拖地后地面有水渍残留 | 水箱密封圈、拖布湿度 |
| 机身漏水 | 水箱、密封圈、水路接头 |
| 无法回充 | 充电触点、基站位置 |
| 原地打转 | 驱动轮、悬崖传感器 |
