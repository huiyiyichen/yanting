# 退货退款受理 SOP（内部）

> 虚构夹具：本文件不是安克官方 SOP，仅用于本 Demo 的检索与证据链路联调。
> **内部资料**：客户接口不得返回本文件原文。

适用产品：全系列
适用地区：全球
适用渠道：不限
版本：2.2.0

## 受理前置条件

生成退货退款申请草稿前，必须已经具备：

1. `product_model`：已确认的单一型号。
2. `country_code`：购买国家/地区。
3. 质保状态结论，或明确记录「无法判断」。
4. 服务路径上需要的经销商授权结论（第三方渠道时）。

任一条件缺失时，只能补问或进入人工复核，**不得**生成申请草稿。

## 受理判定

| 情形 | 处理 |
|---|---|
| 签收 7 日内 + 性能故障 + 非人为损坏 | 可受理退货申请 |
| 签收 7—15 日 + 同类情形 | 转为换货申请 |
| 超出 15 日 | 转维修流程 |
| 人为损坏（进液、跌落、私拆） | 不受理免费退换，可提供付费维修 |
| 凭证缺失 | 先补凭证，不得直接判定不受理 |
| 订单未命中 + 第三方渠道 | 先做经销商授权核验 |

（上述天数为中国大陆地区口径；其他地区按当地政策文件，**不得跨地区套用**。）

## 申请内容要求

申请草稿必须包含：

- 申请类型、关联订单、已确认型号。
- 质保状态及其依据来源。
- 用户诉求与已完成的排障步骤。
- 缺失信息清单（如有）。

## 人工确认

- 退款、换货属于高风险动作，**必须**由售后客服在 Demo 后台确认。
- 系统可以生成草稿，但不得自动执行。
- 批准只代表 Demo 中的申请获得确认，**不代表**真实退款已完成。
- 未操作时保持待确认，不设置处理时限、不自动批准、不自动升级。

## 禁止事项

- 不得在承诺中使用「一定能退」「保证赔偿」等表述。
- 不得在无依据时给出退款金额。
- 不得把草稿状态展示为已提交业务系统。
